## 🇵🇱 Polski

Repozytorium zawiera katalog `EFI` przygotowany dla **ASUS Transformer 3 Pro T303UA** z procesorem Intel Core i5-6200U i grafiką Intel HD Graphics 520. Oryginalne notatki wskazują konfigurację OpenCore 0.7.8 testowaną z macOS Monterey 12.3.

### 🧩 Sprzęt
| Komponent | Informacja |
|---|---|
| Model | ASUS Transformer 3 Pro T303UA |
| CPU | Intel Core i5-6200U 2.30 GHz |
| RAM | 4 GB DDR3 |
| GPU | Intel HD Graphics 520 |
| Bootloader | OpenCore 0.7.8 |
| System testowy | macOS Monterey 12.3 |

### 📁 Zawartość
- `EFI/` — konfiguracja rozruchowa OpenCore przechowywana w repozytorium

### ⚠️ Ważne przed użyciem
Konfiguracje Hackintosh są silnie zależne od konkretnego sprzętu, wersji BIOS/UEFI i wersji macOS. Zrób kopię własnego EFI przed zmianami i sprawdź `config.plist`, SMBIOS, mapowanie USB oraz ustawienia BIOS pod swój egzemplarz urządzenia.

To repozytorium nie zawiera macOS. System należy pozyskać legalnie z oficjalnych źródeł Apple.

## 🇬🇧 English

This repository contains an `EFI` folder prepared for the **ASUS Transformer 3 Pro T303UA** with an Intel Core i5-6200U processor and Intel HD Graphics 520. The original project notes identify OpenCore 0.7.8 and macOS Monterey 12.3 as the tested setup.

### 🧩 Hardware
| Component | Information |
|---|---|
| Model | ASUS Transformer 3 Pro T303UA |
| CPU | Intel Core i5-6200U 2.30 GHz |
| RAM | 4 GB DDR3 |
| GPU | Intel HD Graphics 520 |
| Bootloader | OpenCore 0.7.8 |
| Tested OS | macOS Monterey 12.3 |

### 📁 Repository contents
- `EFI/` — OpenCore boot configuration stored in this repository

### ⚠️ Before using
Hackintosh configurations are highly hardware-, BIOS/UEFI- and macOS-version-specific. Back up your existing EFI and review `config.plist`, SMBIOS data, USB mapping and firmware settings for your exact machine before booting.

This repository does not provide macOS. Obtain the operating system legally from official Apple sources.
