## 🚀 About

This repository contains an **OpenCore EFI reference configuration for the ASUS Transformer 3 Pro T303UA** with Intel Core i5-6200U and Intel HD Graphics 520.

The original project notes identify **OpenCore 0.7.8** and **macOS Monterey 12.3** as the tested combination. The repository is intended as a hardware-specific reference for users researching this exact model, not as a universal Hackintosh EFI.

It is useful for searches such as **ASUS T303UA Hackintosh**, **Transformer 3 Pro OpenCore**, **i5-6200U Hackintosh**, **Intel HD 520 OpenCore** and **Skylake Monterey EFI**.

## ⚠️ Before Using This EFI

Hackintosh configurations are highly dependent on the exact device revision, BIOS/UEFI configuration and macOS/OpenCore version.

Before booting:

- back up your current EFI
- review `config.plist`
- generate/use your own appropriate SMBIOS data
- verify USB mapping
- review BIOS/UEFI settings
- confirm compatibility with your macOS and OpenCore versions

This repository does **not** distribute macOS. Obtain the operating system legally from Apple and review Apple's applicable license terms for your intended use.
